# Black River Concrete

Static website preview for Black River Concrete, serving Lorain County, Ohio and surrounding areas.

## Run
Open `index.html` directly, or serve this directory using any static web server. No package installation or build step is needed.

## Deployment readiness
- Publish directory: repository root.
- Build command: none.
- No runtime environment variables or credentials.
- No backend, tracking, database, or external dependencies.
- Estimate form is intentionally non-submitting; connect an approved destination before launch.
- Preview banner and `noindex,nofollow` remain until final launch approval.
- `robots.txt` disallows crawling. This is not access control: keep the repository private and do not enable public hosting until approved.

## Assets
Project photographs are user-provided originals. Their image bytes have not been retouched or AI-altered. The original brand presentation image supplies only the clipped primary-logo region displayed in the header; replace it with an approved standalone logo for production. Fonts and license are bundled locally.

## Verification
JavaScript syntax, local links and assets, unique IDs, photo integrity, and mocked DOM behavior checks passed. Desktop/mobile browser rendering remains unverified due to execution-environment restrictions. No live hosting has been configured.
